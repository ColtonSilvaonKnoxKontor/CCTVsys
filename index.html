Security Concerns: MUST READ

The webpage is hosted from the home's system unit, which operates 24/7 and is accessible on the internet. Although this webpage is not indexed by search engine bots like Google, Baidu (China), Yandex (Russia), Bing (Microsoft), Yahoo, Yahoo Japan, or DuckDuckGo, anyone with the link can still access it directly. To ensure privacy, ensure the link is kept private and shared only with trusted family members, as unauthorized individuals who obtain the link could view the footage without permission.

The Surveillance CAMERA system is still in testing stage and it is subjected for further adjustment for motion and PTZ, and other configurations to improve the camera itself and streaming quality. Also this server is unstable as the webpage might not load for unexpected issues.
